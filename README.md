# ☁️ Sky-Pulse

 Sky-Pulse — A modern weather website built with React and Tailwind CSS, providing real-time weather information in a clean and user-friendly interface.

## 🛠️ Technologies Used

- React.js
- Tailwind CSS
- JavaScript
- Weather API

## ✨ Features

- Search weather by city
- Displays current weather information
- Temperature information
- Weather conditions
- Responsive design
- Clean and modern UI
